# 微信步数

微信步数是面向安卓微信的 LSPosed 模块。作者为 [wuhua0871](https://wuhua0871.com)。
首页显示今日生效步数、真实步数和每日浮动目标。

## 1.6-beta3 测试版

底部的「诊断」会弹出报告，用户可以先查看，再复制或通过邮件反馈。首页处于「等待读取」且微信的运动识别权限未授予时，会显示「去检查运动权限」。

## 安装和使用

**国内下载**　[应用资源站 · 微信步数](https://app.wuhua0871.com/resources/wechat-step)

1. 从 [Releases](https://github.com/Xposed-Modules-Repo/com.wuhua0871.wechatsteps/releases) 下载 `WeChatSteps-1.6-beta3.apk`。已安装旧公开版的用户可直接覆盖升级。
2. 在 LSPosed 或 Vector 中启用模块，作用域仅勾选微信。如果同时装有其他微信步数模块，请先关闭它们的微信作用域。
3. 如果首页显示「等待加载」，点「去微信应用信息」，在系统页点「强行停止」，返回模块后点「打开微信」。
4. 如果首页提示「去检查运动权限」，在微信应用信息的「权限」中允许「运动识别」，再打开微信运动。
5. 保存设置后，微信在下一次读取时使用新设置。首页显示最近一次读取或进入上报流程的时间。微信运动按自己的周期更新。

## 诊断与反馈

- 「等待读取」表示当前模块构建已留下加载记录，正在等待步数记录。「已读取」表示模块已记录当天步数。「记录失败」会显示错误阶段和时间。
- 点页面底部「诊断」，查看机型、Android 和 ROM 版本、微信构建号、运动识别权限、计步传感器状态，以及本次首次读取、进入上报流程和成功保存的时间。
- 点「复制诊断报告」可粘贴到酷安等反馈帖。「邮件反馈」会把同一份报告填入草稿，由用户确认发送。
- 如果报告没有回调记录，可以一并附上 LSPosed 或 Vector 日志中包含 `WeChatSteps` 的几行。

## 兼容范围

历史版本已在 Play 版微信 8.0.79（3183）上验证模块加载。腾讯国内版 8.0.79（3200）和 8.0.80（3220）通过安装包方法识别。当前测试版继续收集不同机型的计步反馈。

# 微信步数

微信步数是面向安卓微信的 LSPosed 模块。作者为 [wuhua0871](https://wuhua0871.com)。

1.5 将今日生效步数、真实步数、浮动目标和微信适配状态集中在首页。状态为「已加载」时，可以开启步数修改。状态为「识别失败」时，微信继续使用真实步数。

## 使用

1. 安装 Release 中的 WeChatSteps-1.5.apk。公开版 1.4 用户可直接覆盖升级。
2. 在 LSPosed 或 Vector 中启用模块，作用域仅勾选微信。如果还有其他步数修改模块用于微信，先关闭其微信作用域。
3. 彻底退出微信并重新打开。返回「微信步数」，查看适配状态。
4. 在「步数设置」中输入目标，开启修改并保存。每日浮动目标在输入值的 ±10% 内，07:00 至 20:30 逐渐增加，其余时段随真实步数增加。

首页显示模块最近读取或进入上报流程时的记录。排行榜由微信按自己的周期更新。

## 兼容范围

模块自动识别微信计步方法。微信更新后会重新识别。1.4 已验证 Play 版微信 8.0.79（3183）在 Vector 中加载，腾讯国内版 8.0.78（3180）、8.0.79（3200）和 8.0.80（3220）通过安装包识别。1.5 沿用相同的计步逻辑。

# 微信步数

微信步数是面向安卓微信的 LSPosed 模块。作者为 [wuhua0871](https://wuhua0871.com)。
首页显示今日生效步数、真实步数和每日浮动目标。

## 1.6-beta2 测试版

本次测试版处理首次启用或升级模块后微信仍在旧进程运行的问题。首页会核对微信最近加载的模块构建号，并在「等待加载」时提供进入微信应用信息的入口。

## 安装和使用

**国内下载**　[应用资源站 · 微信步数](https://app.wuhua0871.com/resources/wechat-step)

1. 从 [Releases](https://github.com/Xposed-Modules-Repo/com.wuhua0871.wechatsteps/releases) 下载 `WeChatSteps-1.6-beta2.apk`。已安装公开版的用户可直接覆盖升级。
2. 在 LSPosed 或 Vector 中启用模块，作用域仅勾选微信。如果同时装有其他微信步数模块，请先关闭它们的微信作用域。
3. 如果首页显示「等待加载」，点「去微信应用信息」，在系统页点「强行停止」，返回模块后点「打开微信」。
4. 保存设置后，微信在下一次读取时使用新设置。首页显示最近一次读取或进入上报流程的时间。微信运动按自己的周期更新。

## 反馈兼容问题

- 首页显示「等待读取」时，当前模块构建已留下加载记录，正在等待读数。
- 「已读取」表示模块已记录当天步数。「记录失败」会显示发生时间和错误类型。
- 点「邮件反馈」可预填诊断报告，确认后发送。点「复制诊断信息」可以把同一份报告粘贴到酷安等反馈帖。
- 诊断报告包括机型、Android 版本、微信构建号、模块状态和时间。如果一直显示「等待加载」，请同时附上 LSPosed 或 Vector 日志中包含 `WeChatSteps` 的几行。

## 兼容范围

历史版本已在 Play 版微信 8.0.79（3183）上验证模块加载。腾讯国内版 8.0.79（3200）和 8.0.80（3220）通过安装包方法识别。当前测试版用于验证不同手机上的加载和诊断反馈流程。
